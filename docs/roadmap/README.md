## 进度状态约定

- `Pending` —— 还没开始
- `In Progress` —— 正在做
- `Blocked` —— 等其他 Phase / 等用户决策
- `Done` —— 满足 [`definition-of-done.md`](../governance/definition-of-done.md) 中对应 Phase 的全部 DoD
- `Skipped` —— 显式决定不做（必须有 ADR）
