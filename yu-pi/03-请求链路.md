# 03 · 请求链路导读

> 目标：用户点按钮后发生了什么。画出**完整调用链**，标注文件路径 + 类名 + 方法名。

本项目有 **3 条核心链路** + **1 条旁路链路**（评测）。

---

## 链路一：创建应用（含 AI 路由决策）

**触发**：用户在前端输入 prompt，点"创建应用"
**HTTP**：`POST /app/add`

```
[前端] 用户点"创建应用"
   │
   ▼  POST /app/add  body: AppAddRequest{initPrompt}
┌──────────────────────────────────────────────────────────────┐
│ src/main/java/com/prompt2app/app/controller/AppController.java│
│ 类: AppController                                            │
│ 方法: addApp(AppAddRequest, HttpServletRequest)             │
│   - 参数校验: ThrowUtils.throwIf(...)                        │
│   - 获取登录用户: userService.getLoginUser(request)         │
│   - 调 service: appService.createApp(appAddRequest, user)    │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ app/service/impl/AppServiceImpl.java                         │
│ 类: AppServiceImpl                                           │
│ 方法: createApp(AppAddRequest, User)                        │
│   1. 构造 App 实体，appName = initPrompt 前12字             │
│   2. ★ 调 Router 决定 codeGenType                            │
│      routingService.route(initPrompt) → RoutingDecision     │
│   3. app.setCodeGenType(strategy.getValue())                 │
│   4. this.save(app)  → AppMapper → MySQL                    │
│   5. generationMetricService.recordRouting(...) 落监控表    │
│   6. 返回 appId                                             │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ router/RoutingService.java                                  │
│ 类: RoutingService                                          │
│ 方法: route(String userPrompt) → RoutingDecision            │
│   - Layer 1: ruleRouter.route(prompt)                       │
│       命中 → withDuration 返回 (毫秒级, confidence=0.9)      │
│       未命中 → Optional.empty()                              │
│   - Layer 2: llmFactory.create().routeCodeGenType(prompt)  │
│       命中 → 返回 (confidence=0.6)                           │
│   - 最终兜底: LLM 异常 → HTML (confidence=0.3)               │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
        ┌────────────────────┴────────────────────┐
        ▼                                         ▼
┌───────────────────────┐         ┌────────────────────────────────────┐
│ router/RuleRouter.java│         │ router/AiCodeGenTypeRoutingService│
│ 方法: route(String)   │         │  (LangChain4j 接口)                │
│  - MULTI_FILE 关键词  │         │ @SystemMessage(fromResource=       │
│  - MULTI_FILE 正则    │         │   "prompt/codegen-routing-...txt") │
│  - VUE 关键词         │         │ 方法: routeCodeGenType(String)     │
│  - HTML 短小判定      │         │   → CodeGenTypeEnum (结构化输出)   │
│  - 都不命中→empty    │         │   → 调 LLM (OpenAI/DashScope)      │
└───────────────────────┘         └────────────────────────────────────┘
```

**关键认知**：
- 路由决策**在创建应用时就做好了**，写入 `app.code_gen_type` 字段
- 之后对话时直接读这个字段，不再重新路由
- `RoutingDecision` 携带 `layer` / `reason` / `confidence` / `durationMs` 元数据，落 `generation_metric` 表

## 链路二：对话生成代码（核心 · SSE 流式）

**触发**：用户在应用里输入消息，点发送
**HTTP**：`GET /app/chat/gen/code`（SSE 长连接）

```
[前端] 用户输入消息，点发送
   │
   ▼  GET /app/chat/gen/code?appId=1&message=做一个咖啡店官网
   │   Accept: text/event-stream
┌──────────────────────────────────────────────────────────────┐
│ app/controller/AppController.java                           │
│ 方法: chatToGenCode(Long appId, String message, request)    │
│   返回: Flux<ServerSentEvent<String>>                       │
│   - @RateLimit(USER, rate=5, interval=60s)                  │
│     → infra/ratelimiter/aspect/RateLimitAspect 切面拦截    │
│   - 参数校验                                                 │
│   - userService.getLoginUser(request)                      │
│   - appService.chatToGenCode(appId, message, user)         │
│   - 包成 SSE: chunk → {"d": chunk}                          │
│   - 结束事件: event=done                                    │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ app/service/impl/AppServiceImpl.java                       │
│ 方法: chatToGenCode(Long, String, User) → Flux<String>     │
│   1. 查应用 + 权限校验                                      │
│   2. 读 app.codeGenType → CodeGenTypeEnum                  │
│   3. chatHistoryService.addChatMessage(用户消息先落库)     │
│   4. MonitorContextHolder.setContext(userId/appId)        │
│   5. ★ aiCodeGeneratorFacade.generateAndSaveCodeStream(...)│
│   6. streamHandlerExecutor.doExecute(...)                    │
│      (收集 AI 回复，结束后保存 chat_history)                │
│   7. doFinally: MonitorContextHolder.clearContext()        │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ agent/codegen/AiCodeGeneratorFacade.java                    │
│ 类: AiCodeGeneratorFacade  (门面模式)                       │
│ 方法: generateAndSaveCodeStream(String, CodeGenTypeEnum,   │
│        Long appId) → Flux<String>                           │
│   - factory.getAiCodeGeneratorService(appId, type)          │
│   - switch(type):                                           │
│     HTML    → generateHtmlCodeStream → processCodeStream   │
│     MULTI   → generateMultiFileCodeStream → processCodeStream│
│     VUE     → generateVueProjectCodeStream(TokenStream)    │
│              → processTokenStream                           │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
        ┌────────────────────┴────────────────────┐
        ▼ HTML/MULTI_FILE                         ▼ VUE_PROJECT
┌──────────────────────────────┐    ┌──────────────────────────────┐
│ processCodeStream(Flux)      │    │ processTokenStream(TokenStr) │
│ - doOnNext: codeBuilder.append│    │ - onPartialResponse: 推 SSE  │
│ - doOnComplete:              │    │ - beforeToolExecution:       │
│   CodeParserExecutor.execute │    │     推工具请求 SSE           │
│   CodeFileSaverExecutor.exec │    │ - onToolExecuted: 推结果 SSE │
│                              │    │ - onCompleteResponse:       │
│                              │    │     VueProjectBuilder.build()│
│                              │    │     sink.complete()          │
└──────────────┬───────────────┘    └──────────────┬───────────────┘
               ▼                                   ▼
┌──────────────────────────────┐    ┌──────────────────────────────┐
│ codegen/parser/              │    │ agent/tools/ (Tool Calling) │
│  CodeParserExecutor.java     │    │  - ReadFileTool             │
│   switch(type):              │    │  - WriteFileTool             │
│    HTML → HtmlCodeParser     │    │  - DeleteFileTool            │
│    MULTI → MultiFileParser   │    │  - ListFileTool              │
│                              │    │  - CreateDirTool             │
│ 每个工具调用都经过:         │    │                              │
│  agent/tools/safety/          │    │ 每次调用经过三层安全:       │
│   ├ PathValidator (Layer1)    │    │  ├ PathValidator (Layer1)   │
│   ├ Sandbox (Layer2)          │    │  ├ Sandbox (Layer2)         │
│   └ ToolCallCounter (Layer3)  │    │  └ ToolCallCounter (Layer3) │
└──────────────────────────────┘    └──────────────────────────────┘
               ▼
┌──────────────────────────────────────────────────────────────┐
│ codegen/saver/CodeFileSaverExecutor.java                   │
│  switch(type):                                              │
│   HTML  → HtmlCodeFileSaverTemplate                         │
│   MULTI → MultiFileCodeFileSaverTemplate                    │
│  → 写到 tmp/code_output/{type}_{appId}/                     │
└──────────────────────────────────────────────────────────────┘
```

**关键认知**：
- HTML/MULTI_FILE 是"先流式吐代码给前端 → 流结束再解析保存"
- VUE_PROJECT 是"LLM 边吐边调 Tool 写文件 → 完成后 build"
- 这是为什么 Vue 路径评分器要查 dist 目录：build 后才有 `dist/index.html`
- `@RateLimit` 限流 5 次/分钟（防止刷接口烧 token）

## 链路三：应用部署

**触发**：用户点"部署"
**HTTP**：`POST /app/deploy`

```
[前端] 用户点部署
   │
   ▼  POST /app/deploy  body: AppDeployRequest{appId}
┌──────────────────────────────────────────────────────────────┐
│ AppController.deployApp(appDeployRequest, request)          │
│   - 校验 appId                                              │
│   - getLoginUser                                            │
│   - appService.deployApp(appId, user) → 返回部署 URL       │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────────┐
│ AppServiceImpl.deployApp(Long appId, User loginUser)       │
│   1. 查 app + 权限校验                                      │
│   2. 生成/复用 deployKey (6位随机串)                       │
│   3. 源目录: {codeOutputDir}/{type}_{appId}                │
│   4. ★ 若 VUE_PROJECT:                                     │
│      vueProjectBuilder.buildProject(sourceDirPath)         │
│      → 检查 dist 目录                                       │
│      sourceDir = distDir  (部署 dist 而非源码)             │
│   5. 复制到 {codeDeployDir}/{deployKey}                    │
│   6. 更新 app 表 deployKey + deployedTime                  │
│   7. appDeployUrl = {codeDeployHost}/{deployKey}/          │
│   8. ★ generateAppScreenshotAsync(appId, url)              │
│   9. 返回 url                                               │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
        ┌────────────────────┴────────────────────┐
        ▼ VUE 构建                                ▼ 异步截图
┌──────────────────────────────┐    ┌──────────────────────────────┐
│ codegen/builder/             │    │ generateAppScreenshotAsync  │
│   VueProjectBuilder.java     │    │  Thread.startVirtualThread(│
│  - 执行 npm install          │    │    () -> {                  │
│  - 执行 npm run build         │    │      screenshotService      │
│  - 返回 buildSuccess         │    │       .generateAndUpload...  │
│                              │    │      updateById(cover=url)  │
│                              │    │    }                        │
│                              │    │  )                          │
│                              │    │  (JDK21 虚拟线程, 非阻塞)   │
└──────────────────────────────┘    └──────────────┬───────────────┘
                                                    ▼
                                    ┌──────────────────────────────┐
                                    │ service/impl/                │
                                    │   ScreenshotServiceImpl.java │
                                    │  - Selenium WebDriver 截图   │
                                    │  - COS 上传                  │
                                    │  - 返回 url                  │
                                    └──────────────────────────────┘
```

**关键认知**：
- Vue 项目部署前必须先 build，HTML/MULTI_FILE 直接复制源码
- 部署目录用 `deployKey`（6 位随机串）做 URL，不用 appId（防遍历）
- 截图用 **JDK21 虚拟线程**异步执行，不阻塞部署响应

## 链路四：评测（旁路 · 命令行运行）

**触发**：`mvn exec:java -Dexec.mainClass=com.prompt2app.eval.EvalRunner`
**不在 web 链路**

```
[命令行] EvalRunner.main(args)
   │
   ▼
┌──────────────────────────────────────────────────────────────┐
│ eval/EvalRunner.java  或  MultiRoundEvalRunner.java        │
│ 方法: runFull(casesDir, reportFile, prevReport, scorers)   │
│   for (EvalCase ec : loader.loadAll(casesDir)):            │
│     inv = invoker.invoke(ec)      ← 跑生成 + 拿产物         │
│     fs  = composite.score(ec, inv) ← 三维打分              │
│   diff = DiffReporter.diff(finalScores, prevReport)        │
│   reporter.writeFull(runs, invoker, diff, reportFile)      │
└──────────────────────────┬───────────────────────────────────┘
                           ▼
        ┌────────────────────┴────────────────────┐
        ▼                                          ▼
┌──────────────────────────────┐    ┌──────────────────────────────┐
│ eval/DirectServiceInvoker    │    │ eval/CompositeScorer         │
│  .invoke(EvalCase)           │    │  - RubricScorer  (确定性)    │
│  - 调 AiCodeGeneratorFacade  │    │  - RenderScorer  (渲染验证)  │
│  - 跑生成                    │    │  - LlmJudgeScorer (LLM 评分) │
│  - 读 mergedOutput           │    │  → 加权汇总                 │
│  - 返回 InvocationResult     │    │                              │
└──────────────────────────────┘    └──────────────────────────────┘
```

**关键认知**：
- 评测是**旁路**，不进 web 请求链路，独立命令行运行
- `DirectServiceInvoker` 复用了主链路的 `AiCodeGeneratorFacade`，保证评测的是真实生成逻辑
- `MultiRoundEvalRunner`（ADR-0013）跑 3 轮取均分 + 标准差，抑制 LLM 抽样波动

## 横切关注点：AOP 拦截

### @RateLimit 限流
```
任意 Controller 方法标了 @RateLimit
   │
   ▼
infra/ratelimiter/aspect/RateLimitAspect.java  (@Aspect)
   - 前置: Redisson 滑动窗口检查
   - 超限: 抛 BusinessException(ErrorCode.TOO_MANY_REQUESTS)
   - 支持 RateLimitType.USER (按用户) / IP
```

### @AuthCheck 权限
```
Controller 方法标了 @AuthCheck(mustRole = ADMIN_ROLE)
   │
   ▼
infra/aop/AuthInterceptor.java  (通过 @Aspect)
   - 前置: 取 loginUser, 校验角色
   - 不符: 抛 NO_AUTH_ERROR
```

## 完整调用链一句话总结

| 链路 | 一句话 |
|---|---|
| 创建应用 | Controller → Service → **Router（规则+LLM）** → 入库 + 落监控表 |
| 对话生成 | Controller → Service → **Facade → LLM → 解析+保存**（SSE 流式）|
| 部署 | Controller → Service → **Vue build（若是 Vue）→ 复制到部署目录 → 异步截图** |
| 评测 | 命令行 → **Invoker 复用 Facade → 三维 Scorer → DiffReporter** |
