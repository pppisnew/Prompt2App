## 一、项目一句话介绍

**Prompt2App 是一个 AI 网页生成平台**：用户输入自然语言描述（"做一个咖啡店官网"），系统调用 LLM 自动生成完整网站代码（HTML / 多文件 / Vue 项目），支持实时预览、部署、截图、下载。

> **解决什么问题**：把"会说话就能做网页"这件事工程化——LLM 不是简单调一下 API，而是作为**可路由、可防护、可评测**的工程组件嵌入业务系统。

---

## 二、核心业务流程（最简版）

```
用户输入 prompt + 点"创建应用"
        ↓
   AI Router 决策生成策略（HTML / 多文件 / Vue）
        ↓
   创建应用记录入库（app 表 codeGenType 字段）
        ↓
   用户在应用里继续对话 → LLM 流式生成代码（SSE）
        ↓
   代码解析 → 保存到磁盘
        ↓
   用户点"部署" → 复制到部署目录 → 生成可访问 URL
        ↓
   异步截图 → 更新封面
```

**两条主链路**：
1. **创建应用**：`AppController.addApp` → `AppServiceImpl.createApp` → `RoutingService.route` → 入库
2. **对话生成代码**：`AppController.chatToGenCode` → `AppServiceImpl.chatToGenCode` → `AiCodeGeneratorFacade` → LLM 流式 → 解析+保存

## 五、项目启动流程

### 启动入口

`src/main/java/com/prompt2app/Prompt2AppApplication.java`:

```java
@EnableCaching                    // 1. 开启缓存（Redis 后端）
@SpringBootApplication            // 2. Spring Boot 自动装配
@MapperScan({"...app.mapper", "...metric.mapper"})  // 3. 扫描 Mapper
public class Prompt2AppApplication {
    public static void main(String[] args) {
        SpringApplication.run(Prompt2AppApplication.class, args);
    }
}
```

### Spring Boot 启动时发生了什么

1. **加载 `.env`** → `spring-dotenv` 把 `.env` 注入 Spring Environment（优先级低于 OS env / CLI 参数）
2. **绑定配置** → `Prompt2AppProperties`（`@ConfigurationProperties("prompt2app")`）把 `prompt2app.*` 配置项绑定成强类型对象
3. **自动配置 Bean**：
   - `RedisCacheManagerConfig` → 配置 Redis 缓存
   - `StreamingChatModelConfig` / `ReasoningStreamingChatModelConfig` → 创建 LLM ChatModel Bean
   - `RoutingAiModelConfig` → 路由用的 ChatModel
   - `CosClientConfig` → 腾讯云 COS 客户端
   - `CorsConfig` → 跨域
   - `JsonConfig` → Jackson 配置
4. **扫描 `@Service` / `@RestController`** → 业务 Bean 注册
5. **MyBatis-Flex 初始化** → Mapper 代理生成
6. **AOP 切面注册** → `@RateLimit` / `@AuthCheck` 切面就位
7. **Tomcat 启动** → 监听端口（默认 `server.port`，从 `.env` 读）

### 最先加载的关键模块

```
配置加载 → Bean 装配 → DB/Redis 连接池 → AOP 切面 → Controller 就位
```

## 七、几个关键认知锚点（先记住这些）

1. **业务流程上**：创建应用时做路由决策（写 `app.codeGenType`），对话时按类型生成代码
2. **架构上**：`app` 是业务层 / `agent` 是 AI 层 / `router` 是入口分类器 / `eval` 是出口质检 / `infra` 是横切
3. **AI 不是黑盒**：通过 Router 分派、Sandbox 防御、Eval 评测三道关卡把 LLM 纳入工程治理
4. **LangGraph4j workflow 包是演示用**，主路径走 `AiCodeGeneratorFacade`，不要被 `WorkflowSseController` 误导
5. **配置全在 `.env`**，`application.yml` 只留骨架，业务代码不出现硬编码
